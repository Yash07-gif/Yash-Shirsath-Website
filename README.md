## 📌 Overview

In today’s competitive tech landscape, having a strong digital presence is essential.
This portfolio website serves as a **central hub** for recruiters, hiring managers, and collaborators to explore:

* My professional background
* Technical and analytical projects
* Tools & technologies I work with
* Articles and learnings
* Resume and contact details

The website is **fully responsive**, visually clean, and easy to navigate across **desktop, tablet, and mobile devices**.

## 🎯 Purpose of the Project

The main objectives of this project are:

* To present my skills and projects in a structured manner
* To build a professional online identity
* To demonstrate my frontend development skills
* To provide quick access to my resume and contact details
* To create a living portfolio that grows with my career

---

## 🛠️ Technologies Used

### Frontend

* **HTML5** – Semantic structure and layout
* **CSS3 / SCSS** – Styling, responsiveness, and animations
* **JavaScript** – Interactivity and dynamic behavior

### Tools & Utilities

* **SCSS Preprocessor** – Modular and maintainable styling
* **Prepros** – SCSS compilation and asset management
* **Vercel** – Deployment and hosting

---

## 📂 Project Structure

* **css/** – Compiled CSS files
* **scss/** – SCSS source files
* **js/** – JavaScript functionality
* **images/** – Website images and icons
* **fonts/** – Custom fonts
* **lib/** – External libraries
* **index.html** – Main entry point
* **prepros-6.config** – Prepros configuration
* **README.md** – Project documentation
